# Customer Behavior Analysis

This project is based on customer behavior analysis using Python, MySQL, and Power BI. The data was cleaned, analyzed, and then used to create an interactive dashboard.

## Tools Used

* Python (Pandas)
* MySQL
* Power BI
* DAX

## Project Workflow

* Cleaned the data using Python and Pandas
* Analyzed the data using MySQL queries
* Created the dashboard in Power BI
* Used DAX for calculations and measures

## Dashboard Features

* KPI tracking
* Revenue analysis
* Customer segmentation
* Interactive filters
* Charts and visualizations

## Files Included

* `Customer Behavior Dashboard.pbix` – Power BI dashboard
* `Clean_file.ipynb` – Data cleaning and analysis
* `sql_queries.sql` – SQL queries used for analysis
* `Screenshot.png` – Dashboard screenshot
